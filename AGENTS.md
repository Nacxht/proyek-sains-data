# AGENTS.md

## Project Overview
Repository for Data Science assignments ("Proyek Sains Data") published as a static website/book via MyST Markdown / Jupyter Book (v2 / `mystmd`).

## Environment & Toolchain
- **Python Virtualenv**: `.venv/` (Python 3.13) containing data science dependencies (`openeo`, `xarray`, `pandas`, `numpy`, `netCDF4`, `matplotlib`, `folium`) and `jupyter-book` CLI.
- **Jupyter Book / MyST**: Run using `./.venv/bin/jupyter-book` (or activate `.venv`).

## Common Commands
- **Activate Virtualenv**: `source .venv/bin/activate`
- **Install Python dependencies**: `pip install -r requirements.txt`
- **Build documentation site (HTML)**:
  ```bash
  ./.venv/bin/jupyter-book build --html
  ```
- **Live preview / dev server**:
  ```bash
  ./.venv/bin/jupyter-book start
  ```

## Structure & Architecture
- `src/`: Main content source directory containing Markdown pages and Jupyter notebooks for each assignment (e.g., `src/tugas_1/`, `src/tugas_2/`).
- `myst.yml`: Central configuration and Table of Contents (`project.toc`). When adding or moving notebook/markdown chapters, ensure `toc` paths in `myst.yml` are kept in sync with files inside `src/`.
- `_build/`: Build output directory generated by Jupyter Book (ignored in git).
- `.github/workflows/deploy.yml`: GitHub Actions workflow that builds the HTML book and deploys it to GitHub Pages on pushes to `main`.
